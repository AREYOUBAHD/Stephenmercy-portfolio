# Stephen Mercy — Official Artist Portfolio

A responsive, single-page portfolio for recording artist Stephen Mercy. The design uses a luxury black-and-gold palette and highlights music, videos, the artist story, and booking enquiries.

## Included
- Responsive desktop and mobile layout
- Black-and-gold editorial styling
- Selected releases: Get Money, BumBum Clap, Odogwu (DeChair), Love & Money, More Money More Nyash, and Controversial (Open Verse)
- Artist biography and AreYouBahd? values
- YouTube discovery links and Instagram profiles
- Keyboard skip link, visible focus states, accessible navigation labels, and reduced-motion support
- No framework, package installation, or build step required

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open [the repository](https://github.com/AREYOUBAHD/Stephenmercy-portfolio) on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. Wait for the deployment to finish. GitHub Pages will show the public site URL in the Pages settings.

## Before public launch
- Replace the monogram hero artwork and typographic covers with approved artist photography and official release covers.
- Replace YouTube search links with direct official track/video links where available.
- Confirm social account URLs and add a dedicated professional booking email or booking form.
- Add the final custom domain, if one is available.
- Review the live site on mobile and desktop after Pages deployment.

## Current limitations
The portfolio uses CSS-generated placeholder artwork rather than official photos or cover files. Music links are YouTube search results, not verified individual track links. The booking CTA opens the artist Instagram profile; no email form or booking backend is configured yet.
