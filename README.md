# Stephen Mercy — Official Artist Portfolio

A responsive, single-page artist portfolio for Stephen Mercy and the AreYouBahd? movement.

## Features
- Responsive layout for desktop and mobile
- Music release cards for Get Money, BumBum Clap, and Odogwu (DeChair)
- Artist biography and AreYouBahd? brand values
- YouTube discovery links and social profiles
- Mobile navigation menu
- No build tools or dependencies required

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open the repository's **Settings** on GitHub.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. After GitHub finishes deploying, the published URL will appear in the Pages settings.

## Before launch
- Replace the abstract hero artwork with an approved Stephen Mercy portrait.
- Replace text-only cover art with official release artwork.
- Confirm all music platform, social, booking, and management contact links.
- Add a professional booking email if desired.

The current music cards link to YouTube search results rather than unverified individual tracks.
